# React Redux Shopping Application

A React-based shopping application built to practise frontend development, reusable components, routing, and centralized state management.

## Features

- Browse and display products
- View product details
- Manage shopping cart items
- Manage application state using Redux Toolkit
- Navigate between pages using React Router

## Technologies Used

- React.js
- JavaScript
- HTML and CSS
- Redux Toolkit
- React Router

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in your browser.

## Project Structure

- `public/` — public assets
- `src/` — React components, styles, and application code
- `package.json` — project dependencies and scripts

## Purpose

This project demonstrates React fundamentals, component-based development, routing, and state management for a shopping application.
